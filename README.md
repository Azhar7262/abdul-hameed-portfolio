# Abdul Hameed — Personal Portfolio

A modern, animated portfolio website for **Abdul Hameed** — Project Coordination | Data Management | IT Support & Training.

Built with pure **HTML + CSS + JavaScript** and **Three.js** — no frameworks, no build step.

## ✨ Features

- 🌍 **3D animated background** — a rotating particle globe (9,000 points) with connection arcs and ambient floating particles, rendered with Three.js
- 🖱️ **Interactive** — globe and camera react to mouse movement; scroll parallax
- ⌨️ **Typing effect** for dynamic role headlines
- 🔢 **Animated counters** for stats
- 🎞️ **Scroll-reveal animations** on every section
- 📱 **Fully responsive** with mobile navigation
- 📄 **Downloadable CV** built into the navbar, about, and contact sections
- ⚡ Zero build tools — open `index.html` and it works

## 📂 Structure

```
├── index.html        # Main page
├── style.css         # Dark glassmorphism theme + animations
├── script.js         # Three.js 3D background + interactions
├── Abdul_Hameed_CV (1).docx   # Downloadable resume
└── Abdul_Hameed_RDP.pdf       # Source CV (reference)
```

## 🚀 Deploy free on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under *Source*, select **Deploy from a branch → main → / (root)**
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
